# 수나래 시간표(학생용)

학생이 공용 비밀번호를 넣고 이름을 골라 시간표와 남은 숙제를 보는 화면입니다.
주소: https://sunaraemath.github.io

- `index.html`: 화면 전체. 원본은 `sunarae-timetable/student/web/index.html`입니다.
- 학생 정보와 비밀번호는 이 저장소에 없습니다. 비밀번호를 확인한 Apps Script 서버(`API_URL`)가 내려 줍니다.
- 비밀번호는 관리 프로그램의 **학생·주간 설정 → 시트·정리**에서 바꿉니다.

## 예전 학원 홈페이지

커밋 `5e9aac6`까지가 예전 홈페이지입니다. 되살리려면 그 커밋의 파일을 꺼내면 됩니다.
