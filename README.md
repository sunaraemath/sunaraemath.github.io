# 수나래 수학학원 홈페이지

GitHub Pages로 올리는 정적 홈페이지입니다. 빌드 과정 없이 파일을 올리면 바로 보입니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `content.js` | **홈페이지 글 전부.** 내용은 이 파일만 고치면 됩니다 |
| `images/` | 마크(`mark.png`), 약도, 원장 사진 |
| `index.html` | 화면 틀과 상담 신청서 항목 |
| `style.css` | 디자인 |
| `site.js` | 화면 전환, 신청서 확인과 전송 |
| `google-apps-script.js` | 신청서를 구글 시트에 저장하는 코드 (구글 쪽에 붙여넣는 용도) |

## 화면 구성

- **PC**: 첫 화면은 왼쪽에 마크와 학원 이름, 오른쪽에 소개 문구. 위 메뉴를 누르면 해당 페이지만 보입니다.
- **모바일** (화면 폭 900px 이하): 첫 화면에 소개, 오시는 길, 상담 신청이 차례로 나옵니다. 원장 소개와 수업 안내는 오른쪽 위 메뉴에서 엽니다.
- 페이지 주소: `#director`(원장 소개), `#classes`(수업 안내), `#location`(오시는 길), `#apply`(상담 신청). 예: `https://주소/#apply`를 보내면 신청서가 바로 열립니다.

## 내용 고치기

1. `content.js`를 엽니다.
2. `[대괄호]` 문구를 실제 내용으로 바꿉니다. 따옴표 안의 글만 바꾸고 쉼표·괄호는 그대로 둡니다.
3. 사진을 넣을 때는 `images/` 폴더에 파일을 올리고 경로를 적습니다. 예: `photo: "images/director.jpg"`, `map: "images/map.png"`

GitHub 웹사이트에서 파일을 열고 연필 아이콘(Edit)으로 고친 뒤 "Commit changes"를 누르면 1~2분 뒤 홈페이지에 반영됩니다.

## GitHub Organization에 올리기

1. Organization 안에 저장소를 만듭니다. 이름을 **`<organization 이름>.github.io`** 로 하면 주소가 `https://<organization 이름>.github.io` 가 됩니다.
2. 이 폴더의 파일을 모두 올립니다. (`.nojekyll` 파일도 함께)
3. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장합니다.
4. 몇 분 뒤 위 주소로 접속해 확인합니다.

## 상담 신청 연결하기 (구글 시트)

신청서 내용이 원장님 구글 시트에 한 줄씩 쌓이도록 연결합니다. 연결 전에는 신청 버튼을 누르면 "접수 기능이 아직 연결되지 않았어요"라고 나옵니다.

1. 구글 드라이브에서 새 구글 시트를 만듭니다. (예: "수나래 상담 신청")
2. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기존 코드를 지우고 `google-apps-script.js` 내용을 통째로 붙여넣습니다.
   새 신청 알림 메일을 받으려면 `NOTIFY_EMAIL = ""` 따옴표 안에 이메일을 적습니다.
4. 저장한 뒤 **배포 → 새 배포** → 유형 **웹 앱** 을 고르고
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   로 배포합니다. 처음에 나오는 권한 허용 창은 본인 계정으로 허용합니다.
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사해
   `content.js`의 `endpoint: ""` 따옴표 안에 붙여넣습니다.
6. 홈페이지에서 시험 신청을 한 번 보내고 시트에 "상담신청" 탭과 한 줄이 생겼는지 확인합니다.

Apps Script 코드를 나중에 고쳤다면 **배포 → 배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영됩니다.

## 개인정보 안내

학생 연락처를 받기 때문에 신청서 아래에 수집 항목·목적·보유 기간을 안내하고 동의를 받습니다. 문구는 `content.js`의 `privacy`에서 고칩니다. 보유 기간이 지난 신청 내역은 시트에서 지워주세요.
